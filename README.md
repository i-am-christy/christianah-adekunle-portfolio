# Christianah Adekunle — Portfolio

Personal site for **Adekunle Christianah Ayomide** (Luna), an AI/ML engineer and first-class Computer Science graduate of FUTA.

The layout follows the structure of [victorakinode.com](https://victorakinode.com/): a gradient hero, community strip, about + stats, expertise cards, project case studies, writing, and a contact page. The copy is drawn from her [GitHub](https://github.com/i-am-christy), [Hashnode](https://i-am-christy.hashnode.dev/), and public LinkedIn posts — not invented.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127). The dev server binds to `127.0.0.1` so Cursor preview and `/_next` assets are not blocked as a cross-origin request.

```bash
npm run build
npm start
```

## Stack
